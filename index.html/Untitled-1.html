02 // MANIFESTO

深 海 の 衝 動。
Theatrics 覚 醒。

PRODUCED BY AVU-CHAN (QUEEN BEE) // 0年0組

規格化された偶像劇を拒絶し、美と劇毒を舞台上に刻みつける7人の異端児。

日本テレビのスクール型オーディション番組『0年0組 -アヴちゃんの教室-』より誕生。女王蜂のヴォーカル・アヴちゃんがプロデュースを手掛け、歌謡曲が内包する哀愁と、オルタナティブロックの攻撃性、コンテンポラリーダンスの緊張感を極限まで昇華させた。

静寂の純白と、熱情を孕んだ深紅（ボルドー）の色彩の中で、観る者の心臓を直接揺さぶる。過酷な試練を超えて結実した圧倒的求心力が、現代の音楽シーンに新たな神話を描き出していく。
